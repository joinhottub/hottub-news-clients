# Hottub News clients

Official clients and agent tools for [Hottub News](https://hottub.news). It
gathers worldwide news from 7,000+ sources in 50+ languages and groups the
reports into stories across outlets and languages. Stories are classified,
translated to English and linked to Wikidata. The API is free and needs no
key.

| Package | Install | Docs |
| --- | --- | --- |
| JavaScript / TypeScript (Node 18+, browsers, Workers) with Vercel AI SDK and LangChain tools | `npm install hottub-news` | [js/](js/) |
| Python 3.9+ with LangChain and LlamaIndex tools | `pip install hottub-news` | [python/](python/) |

Prefer no client at all?
- **MCP:** connect `https://hottub.news/mcp`.
- **Plain HTTP:** start from [llms.txt](https://hottub.news/llms.txt) or the [OpenAPI spec](https://hottub.news/openapi.json).

Paid placements are always labeled in every response.
